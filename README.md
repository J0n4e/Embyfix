# Embyfix (EmbyFlix)

A Netflix-style native macOS client for Emby, written in SwiftUI.

## Features
- Sign in to your Emby server, sidebar navigation, rotating featured banner
- Library pages with sort, filter (unwatched/watched/genre), A–Z jump bar; choices remembered per library
- Movie info page: cast, about, similar titles, version/audio/subtitle/quality pickers
- In-window playback (direct play or HLS transcode), watched marks, favorites
- Search, library customisation, accent/background colour themes

## Run
Requires macOS 14+ and Xcode 15+. Open `Package.swift` in Xcode and press Run (or `swift run`).
